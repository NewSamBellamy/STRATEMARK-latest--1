# Stratemark phases — v2 entry point

[DELIVERY-PLAN.md](DELIVERY-PLAN.md) replaces the former G00–G08 execution sequence.

R0 locks the buildable slice; R1 delivers a real native deck journey; R2 completes seven card types and research destinations; R3 delivers research depth and broad connections; R4 delivers guest sharing; R5 delivers return visits and monitoring; R6 delivers local MCP; R7 delivers supported remote/plugin integrations; R8 verifies the release candidate.

Each phase includes frontend, backend, persistence, recovery and observable user value. Existing implementation evidence is preserved in [BUILD-STATE-V1.md](BUILD-STATE-V1.md). No R-goal is complete or active merely because this plan exists.
