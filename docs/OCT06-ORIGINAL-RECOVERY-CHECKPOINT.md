## Delivered

1. Initial company research, metric hunting and verification now carry explicitly discovered original-source locator lines from grounded notes into bounded original selection. Grounding metadata alone may contain opaque redirect links. Source policy asks for discovered direct URLs, never guessed paths or identifiers. Locator candidates are bounded to 40,000 note characters, 20 primary-host leads, existing URL and reader capability checks, and the existing two-read limit. They do not become metric citations or proof merely because a model supplied them. Actual retained evidence still must match issuer, value, definition and reporting period.
2. Protected metric hunting uses accepted company facts to decide whether a stored machine-verified figure is truly protected. A historical raw verified label with no acceptable original is no longer a permanent recovery deadlock when the public display says Unknown. Human corrections, ambiguous revisions, concurrent metric changes and genuinely supported verified figures remain protected. The write boundary rechecks accepted facts after source retrieval. No additional model calls are introduced on a normal hunt; the extra checks read retained evidence locally.
